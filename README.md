# Laravelを使用したSNS

## 詳細
Laravelで作成したSNSです。  
ログインしなくても、投稿一覧や個別投稿ページ、ユーザーページの閲覧が可能です。  
ログイン・もしくは新規会員登録すると、テキスト・画像の投稿ができるようになります。  
フォロー機能も実装しており、特定のユーザーをフォローすると、「フォロー中の投稿一覧」タブにて該当ユーザーの投稿だけが閲覧できるようになります。  
また、ID「test@test.com」、パスワード「password」でログイン可能です。   

## 使用言語など
Laravel、Tailwind CSS
